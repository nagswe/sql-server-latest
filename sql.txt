sql server datatypes

| Data Type          | Typical Use                       |
| ------------------ | --------------------------------- |
| `int`              | IDs, counters                     |
| `varchar(n)`       | Names, emails, addresses          |
| `nvarchar(n)`      | Unicode text (multiple languages) |
| `decimal(p,s)`     | Financial values                  |
| `bit`              | Boolean values (Yes/No)           |
| `date`             | Birth dates, order dates          |
| `datetime2`        | Timestamps                        |
| `uniqueidentifier` | GUID primary keys                 |
| `varbinary(max)`   | Documents, images                 |

CREATE FUNCTION dbo.fn_AnnualSalary
(
    @Salary DECIMAL(10,2)
)
RETURNS DECIMAL(12,2)
AS
BEGIN
    RETURN @Salary * 12
END;

SELECT EmpName,
Salary,
dbo.fn_AnnualSalary(Salary) AS AnnualSalary
FROM Employee;

CREATE FUNCTION dbo.fn_Bonus
(
    @Salary DECIMAL(10,2)
)
RETURNS DECIMAL(10,2)
AS
BEGIN
    RETURN @Salary * 0.10
END;

SELECT EmpName,
Salary,
dbo.fn_Bonus(Salary) AS Bonus
FROM Employee;

CREATE FUNCTION dbo.fn_ITEmployees()
RETURNS TABLE
AS
RETURN
(
    SELECT *
    FROM Employee
    WHERE Department='IT'
);

SELECT *
FROM dbo.fn_ITEmployees();

CREATE FUNCTION dbo.fn_HighSalaryEmployees
(
    @Salary DECIMAL(10,2)
)
RETURNS @Emp TABLE
(
    EmpID INT,
    EmpName VARCHAR(50),
    Salary DECIMAL(10,2)
)
AS
BEGIN

INSERT INTO @Emp

SELECT EmpID,
EmpName,
Salary
FROM Employee
WHERE Salary>@Salary;

RETURN;

END;
CREATE FUNCTION dbo.fn_Experience
(
    @JoiningDate DATE
)
RETURNS INT
AS
BEGIN
    RETURN DATEDIFF(YEAR,@JoiningDate,GETDATE())
END;

storage procedure
-----------------

A Stored Procedure in SQL Server is a precompiled group of one or more SQL statements stored inside the database. We use procedures to perform reusable operations such as insert, update, delete, search, reporting, and business logic.

For a real-time employee management system, you might create procedures such as:

Update Employee Salary

Search Employees

    Salary DECIMAL(10,2),

    @EmployeeName VARCHAR(100),

    @JobTitle VARCHAR(50),
    @Salary DECIMAL(10,2),

BEGIN

        @JobTitle,
        @Salary,
